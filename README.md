# 坦克大战 · Tank Battle

一个纯 HTML + Canvas + JavaScript 实现的经典坦克大战（Battle City）游戏，无需任何依赖，双击 `index.html` 即可游玩。

## 🎮 玩法

- 操控你的坦克，消灭所有敌方坦克，同时**保卫基地（鹰）**不被摧毁
- 击毁砖墙可以开辟通路，钢墙需要加强火力才能摧毁
- 草丛可以隐藏坦克，水域无法通行

## ⌨️ 操作

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动坦克 |
| `空格` | 开火 |
| `P` | 暂停 / 继续 |
| `回车` | 开始 / 下一关 |

## ✨ 特性

- 多关卡，敌人数量逐关递增
- 可破坏砖墙、钢墙、水域、草丛等经典地图元素
- 敌方 AI 自动移动与射击
- 计分、生命、关卡系统
- 粒子特效、屏幕震动、音效（Web Audio）
- 像素风渲染

## 🚀 运行

直接用浏览器打开 `index.html` 即可，无需服务器或构建步骤。

```bash
# 或使用任意静态服务器
python -m http.server 8000
# 然后访问 http://localhost:8000
```
